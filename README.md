# CloudFileOps

Plataforma backend/cloud para carga, procesamiento y análisis de archivos CSV usando AWS.

## Objetivo

Este proyecto simula un flujo backend/cloud real donde una empresa puede subir archivos CSV, almacenarlos en S3, procesarlos mediante SQS, Lambda o Glue, guardar resultados en PostgreSQL/RDS y consultar estados, errores y métricas mediante APIs seguras.

## Tecnologías previstas

- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Docker
- AWS S3
- AWS SQS
- AWS Lambda
- AWS Glue
- AWS RDS
- AWS CloudWatch
- AWS IAM
- Terraform
- GitHub Actions
- Kubernetes manifests
